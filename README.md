# Tainted Magic: Reforged

Закрытая личная адаптация Tainted Magic 8.2.0 для Minecraft 1.21.1 / NeoForge. Репозиторий предназначен для хранения исходников и проверенной личной сборки.

**Закрытый репозиторий:** релиз и исходники доступны только владельцу и допущенным участникам.

Текущий выпуск: **8.2.0-port.6**.

## Для запуска

Нужны **Minecraft 1.21.1**, **Java 21** и **NeoForge 21.1**; общая сборка проверена на **21.1.264**.

- [Наш Thaumcraft 4: Reforged 1.1-bbtt.30-filter.1](https://github.com/yzs57phbts-web/thaumcraft-4-reforged-dop/releases/tag/1.21.1-bbtt.30-filter.1).
- Curios API **9.5.1** и TerraBlender **4.1.0.8** — зависимости проверенного ядра T4.
- Curios обязателен; Thaumic Tinkerer необязателен.

Скачайте JAR из [релиза 8.2.0-port.6](https://github.com/yzs57phbts-web/tainted-magic-reforged/releases/tag/1.21.1-v8.2.0-port.6) и положите в `mods` вместе с зависимостями. В папке должна быть одна версия каждого мода.

## Добавили

Перенесённое содержимое, доступное в этой версии:

- Мрачный металл, искажённое дерево, материалы и собственные исследования.
- Катаны, ножны, надписи, заряженные удары и полый кинжал.
- Таум-дезинтегратор, набалдашники, улучшения и специальные снаряды.
- Теневая экипировка, руническая защита, ключ возврата и соли погоды/времени.

## Пофиксили

- Восстановлены исходные текстуры клинков, ножен и снарядов.
- Исправлены положение предметов в руках, заряжаемые удары и отображение состояний.
- В port.6 восстановлены звуки и проверенные типы частиц, включая снаряды, вспышки и следы.

## Адаптировали

- Боевые атрибуты, заряд, чары, блокирование и износ перенесены на современную систему.
- Эффекты синхронизируются с наблюдающими клиентами.
- Рунические усиления и текст исследований используют расширения нашего T4.

## Изменили

- Современные параметры оружия и экипировки соответствуют сохранённым настройкам личной сборки.
- Сохранены реестровые идентификаторы, оригинальные ресурсы и русские тексты.

## Совместимость и проверки

Выпуск рассчитан на API нашей доработанной версии T4. Совместимость с чистым авторским T4 автоматически не предполагается.

Опубликованный JAR совпадает по SHA256 с выбранным установленным выпуском. Эта комбинация участвовала в проверке полной сборки: загрузка, настоящий Creative-мир, вкладка T4, прокрутка предметов и повтор после перезагрузки ресурсов. Это не означает полного прохождения всех механик каждого аддона. Подробности текущего выпуска и ограничения сохранены в исходниках/уведомлениях проекта; старые отчёты относятся к своим версиям.

## Сборка из исходников

Положите наш T4 в `libs/` либо задайте `-PcoreJar=/путь/к/T4.jar`. Curios и TerraBlender разрешаются через Maven. Для интеграционного запуска Tinkerer можно положить в `libs/` и включить `-PwithTinkerer`.

```sh
./gradlew build
```

Старые GameTest-классы отделены от обычной сборки. `compileGameTestJava` компилирует их отдельно, `runGameTestServer` подключает их только в тестовом запуске. Вспомогательный игрок взят из исходников нашей базы T4.

Нужен JDK 21. Машинные пути разработчика, эталонные сторонние JAR, игровые миры и конфиги профиля в репозиторий не включены. Скомпилированный выпуск находится в GitHub Releases; `SHA256SUMS.txt` позволяет проверить скачивание.
