# Tainted Magic: Reforged

Неофициальная адаптация Tainted Magic 8.2.0 для Minecraft 1.21.1 / NeoForge. Репозиторий содержит исходники и выбранную сборку для Minecraft 1.21.1 / NeoForge.

Текущий выпуск: **8.2.0-port.6**.

## Для запуска

Нужны **Minecraft 1.21.1**, **Java 21** и **NeoForge 21.1**; общая сборка проверена на **21.1.264**.

- [Наш Thaumcraft 4: Reforged1.0.1](https://github.com/yzs57phbts-web/thaumcraft-4-reforged-dop/releases/tag/1.0.1).
- [Curios API 9.5.1](https://www.curseforge.com/minecraft/mc-mods/curios/files/6529130) и [TerraBlender 4.1.0.1+ для NeoForge](https://www.curseforge.com/minecraft/mc-mods/terrablender-neoforge/files/6054947) — зависимости ядра T4. Для совместных проверок использовался TerraBlender 4.1.0.8.
- Curios обязателен; Thaumic Tinkerer необязателен.

Скачайте JAR из [релиза 8.2.0-port.6](https://github.com/yzs57phbts-web/tainted-magic-reforged/releases/tag/1.21.1-v8.2.0-port.6) и положите в `mods` вместе с зависимостями. В папке должна быть одна версия каждого мода.

Ниже перечислены **отличия относительно исходника**: Tainted Magic 8.2.0 для Minecraft 1.7.10. Исходные предметы и механики сами по себе не считаются добавлениями этой версии.

## Пофиксили

- Исправлены возникшие при переносе положение клинков/ножен в руках, заряжаемые удары и отображение состояний.
- Восстановлено воспроизведение исходных звуков и проверенных типов частиц в современном клиенте.

## Адаптировали

- Боевые атрибуты, заряд, зачарования, блокирование и износ перенесены на систему 1.21.1.
- Частицы и эффекты синхронизируются с наблюдающими клиентами через современные пакеты.
- Рунические усиления и исследования подключены к расширениям нашего T4; ограничения брони на базе 30 описаны ниже.

## Изменили

- Оружие и экипировка используют согласованные современные параметры урона/скорости вместо старой боевой системы 1.7.10.

## Совместимость и проверки

Выпуск рассчитан на API нашей доработанной версии T4. Совместимость с чистым авторским T4 автоматически не предполагается.

Опубликованный JAR совпадает по SHA256 с выбранным установленным выпуском. Эта комбинация участвовала в проверке полной сборки: загрузка, настоящий Creative-мир, вкладка T4, прокрутка предметов и повтор после перезагрузки ресурсов. Это не означает полного прохождения всех механик каждого аддона. Подробности текущего выпуска и ограничения сохранены в исходниках/уведомлениях проекта; старые отчёты относятся к своим версиям.

## Сборка из исходников

Для компиляции сохранённых исходников нужен исторический API T4 **1.1-bbtt.12**: положите `thaumcraft-4-reforged-1.1-bbtt.12-1.21.1.jar` в `libs/` либо передайте его через `-PcoreJar`. Это исходная зависимость проекта. У базы 30 отсутствует `FortressArmorItem.protection`, поэтому она не заменяет этот JAR при компиляции. Саму зависимость в репозиторий не включаем.

На установленной базе 30 проверены загрузка и интерфейс Creative, но специальная защита унаследованной брони не подтверждена: API изменился. Полная совместимость всех механик брони с базой 30 не заявляется.

Curios и TerraBlender разрешаются через Maven. Для интеграционного запуска Tinkerer можно положить в `libs/` и включить `-PwithTinkerer`.

```sh
./gradlew build
```

Старые GameTest-классы отделены от обычной сборки. `compileGameTestJava` компилирует их отдельно, `runGameTestServer` подключает их только в тестовом запуске. Вспомогательный игрок взят из исходников нашей базы T4.

Нужен JDK 21. Машинные пути разработчика, эталонные сторонние JAR, игровые миры и конфиги профиля в репозиторий не включены. Скомпилированный выпуск находится в GitHub Releases; `SHA256SUMS.txt` позволяет проверить скачивание.
